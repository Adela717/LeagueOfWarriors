# League of Warriors

A console-based adventure game developed in Java using object-oriented programming principles.

The player explores a dynamically generated map, fights enemies, uses elemental abilities, gains experience, and progresses through multiple levels.

## Features

- Three character classes: Warrior, Mage, and Rogue
- Turn-based combat with normal attacks and elemental spells
- Dynamically generated maps with enemies, sanctuaries, and portals
- Character health, mana, experience, and level progression
- Account and character data loaded from JSON
- Custom exception handling for invalid commands and movements

## Technologies

Java, Object-Oriented Programming, Java Collections, JSON, json-simple

## Running

Open the project in IntelliJ IDEA, configure the `json-simple` dependency, and run the `Test` class.
